Count programme

Select count frequency by value, velocity, risk and quality sensitivity. Freeze or control affected movements while a count is in progress.

A
ABC cycle counts

Higher-value or high-velocity SKUs counted more frequently, using documented classification rules.

⌖
Location-based counts

Assign defined zones, bins or locations; prevent duplicate or overlapping count assignments.

⚑
Event-triggered counts

Investigate repeated discrepancies, damage, unexplained movement, returns or quality holds.

◷
Scheduled full counts

Plan controlled facility-wide counts with approved cut-off windows and movement reconciliation.

Count execution safeguards

Count against a defined stock snapshot and retain the original ledger quantity separately from the physical observation.

1
Scope and authorise
Facility, zones, SKU/lot, quality status, unit of measure, cut-off time and independent count owner.
2
Blind physical count
Hide expected quantity from the counter where appropriate; capture observed quantity, unit, timestamp and evidence.
3
Second count
Require recount above configured variance thresholds or for controlled/high-risk inventory.
4
Movement reconciliation
Account for receipts, picks, transfers, returns and other movements during the count window.

Variance investigation

A mismatch is an exception to investigate—not an automatic stock correction.

±
Quantity variance

Compare counted and book quantities using the same SKU, lot, location and unit.

◎
Root-cause classification

Mis-pick, receiving error, unrecorded movement, unit conversion, damage, loss or data issue.

⇄
Independent review

Counter cannot approve their own variance; require supporting evidence and a reasoned decision.

✓
Controlled adjustment

Post only through an authorised server-side transaction with idempotency and immutable audit history.

Reconciliation decision path

Keep the count observation, investigation and ledger adjustment as distinct auditable events.

Ledger integrity & backend release gates

The inspected schema includes krim_warehouse_inventory with facility, SKU, lot, quantity, unit, storage location and quality status, plus krim_warehouse_inventory_movements with movement type, quantity delta, reference, actor, timestamp and idempotency key. No cycle-count session, count-line, variance-review or stock-adjustment approval tables/functions were found in this inspection.
