Operational guardrails

This workspace currently provides the secure UI foundation only. It does not record inventory, confirm receipts, or dispatch goods. The live Supabase schema audit found no dedicated warehouse, inventory, stock, facility, put-away, or receiving tables; enabling writes now would be unsafe.

Build sequence

1. Facility and membership scope → 2. Inbound receipt → 3. Stock ledger → 4. Put-away and reservations → 5. Outbound handover → 6. Exception queue and audit tests.
