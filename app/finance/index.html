Financial control framework

01
Payments are not payouts

Customer payment success and partner payout completion are distinct events. Never mark a payout paid based only on checkout success.

02
Reconciliation before settlement

Match provider references, ledger amounts, currency, and shipment/assignment before settlement approval.

03
Least-privilege access

This workspace performs read-only queries. Database row-level security remains the boundary for visible records.
