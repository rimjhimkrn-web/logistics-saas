Acceptable Use Policy & Platform Guardrails

Effective Date: October 1, 2026. Rules governing automated rate scraping, API call thresholds, security probe protections, and acceptable utilization of KRIM OS services.

01. Purpose & System Integrity

This Acceptable Use Policy (AUP) outlines the operational constraints required to protect the availability, integrity, and security of the KRIM OS global network. Compliance with this policy is mandatory for all portal users, enterprise API integrators, carriers, and automated systems.

02. Prohibited System Activities

Users and systems interacting with KRIM OS are strictly prohibited from engaging in any of the following activities:

  • Unauthorized Rate Scraping: Automated extraction, web scraping, or reverse engineering of real-time spot rates, ocean carrier indices, or tariff structures outside authorized API scopes.
  • API Overloading & Denial of Service: Issuing requests in excess of designated tier rate limits, conducting unauthorized stress tests, or initiating DDoS attacks.
  • Fraudulent Booking Submissions: Submitting false container manifests, fictitious Bill of Lading numbers, or fake customs documentation to bypass compliance checks.
  • Credential Sharing & Token Misuse: Sharing API authorization tokens, administrative credentials, or multi-tenant portal sessions across unauthorized third parties.

03. API Rate Limits & Throttling

To ensure deterministic latency across our global edge nodes, KRIM OS enforces standard automated rate limits based on account tiering:

Standard API Tier 100 Req / Min
Enterprise API Tier 2,500 Req / Min
Carrier Telemetry Mesh Dedicated Pipeline

04. Enforcement & Account Suspension

Violations of this AUP may result in immediate IP rate-limiting, revocation of API access tokens, or permanent suspension of enterprise portal access without prior notice. Violations involving illegal customs activity will be escalated directly to international maritime enforcement authorities.
