STAGING REVIEW MODE · Public read-only preview. No customer records, documents, payments, invoices, refunds or settlement data are loaded. No persistent writes are available.

This public staging preview does not issue file links or expose customer documents. Production downloads require a fresh server-side authorization check.

Download eligibility

  • The ePOD record must be independently verified and linked to the correct shipment.
  • The signed-in user must have active organization membership and document permission.
  • A download must be limited to the authorized record and current access context.
  • Expired, revoked or superseded links must not remain usable.

Secure file handling

  • Use private storage and short-lived signed URLs; never expose public bucket paths.
  • Generate links only after a server-side authorization check.
  • Log user, organization, document, timestamp and outcome.
  • Do not treat a successful download as proof that the customer accepted delivery.

If a document is unavailable

  • Show whether evidence is pending, rejected, missing or access-restricted.
  • Do not generate a substitute or placeholder certificate.
  • Provide the shipment reference and a secure support route.
  • Notify users when verified evidence becomes available.

Global operating and security standard

Use organization-scoped authorization, server-confirmed state transitions, UTC event timestamps displayed in the saved IANA timezone, jurisdiction-aware fields and explicit ISO 4217 currency codes. Catalogue presence or a display preference does not establish operational availability. Essential operational and security notifications must be delivered with status tracking and retry handling.
